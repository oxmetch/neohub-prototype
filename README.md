# Neohub — прототип для iPhone

Кликабельный прототип по макету из Paper (40 экранов, 6 сценариев).
Работает как приложение с экрана «Домой» и без интернета — в том числе в самолёте.

## Установка на iPhone (один раз, нужен интернет)

1. Открыть ссылку в **Safari** (не в Chrome и не во встроенном браузере Telegram).
2. Подождать 5–10 секунд, пока всё загрузится.
3. «Поделиться» → «На экран „Домой“» → «Добавить».
4. Запустить Neohub с экрана «Домой» и пролистать пару экранов —
   так приложение точно сохранится для офлайна.
5. Проверка: включить авиарежим, закрыть приложение свайпом и открыть снова.

## Во время показа

- Всё нажимается как в настоящем приложении: кнопки, вкладки, PIN-клавиатура
  (любые 4 цифры), переключатели, выбор тарифа.
- Назад — стрелка в шапке или свайп от левого края экрана.
- **Меню сценариев для ведущего**: три быстрых тапа по самому верху экрана.
  Оттуда можно сразу перейти в любой кейс или начать сначала.

## Сценарии

| Кейс | Путь |
|---|---|
| Старт | Сплэш → Welcome |
| 1 · Физлицо | Стать клиентом → Физлицо → SMS → селфи → PIN → счёт открыт |
| 1 · Юрлицо | БИН → бенефициары → заявка на проверке (через 3 с приходит push) → счета открыты |
| 1 · Astana Hub | Статус участника → что подключить → Founder-карта |
| 2 · Вход | Войти → PIN или Face ID → главная → сервисы |
| 3 · Перевод | Перевод → карта / PayPal / Stripe → подтверждение по Face ID → готово |
| 4 · Платежи | Платежи → оплатить по счёту → проверить → оплатить → готово |
| 5 · Маркетплейс | Маркетплейс → SmartCRM → договор → подключено → мои подписки |
| 6 · Отчёты | Отчётность → отчёт за квартал → приоритетный доход → файлы |

## Обновление

Экраны лежат в `src/screens/` (HTML, экспорт из Paper), логика переходов — в `app.js`.
После правок: `python3 build.py`, затем закоммитить и запушить. На телефоне новая
версия подтянется при следующем запуске с интернетом.
